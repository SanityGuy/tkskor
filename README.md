# TKScore

> A fast, transparent calculator for estimating TKA/TKAD-based academic scores.

TKScore is a free, open-source web application that helps students estimate their final academic score using their **TKA**, **TKAD when applicable**, and **report card average**.

Built with React and Vite, TKScore performs calculations entirely on the client side and requires no account or sign-in.

## ✨ Features

* 🧮 **TKA Calculator**

  * Bahasa Indonesia
  * Mathematics

* 📍 **TKAD Support**

  * Optional TKAD calculation
  * Designed for the **Special Region of Yogyakarta**
  * English
  * Science

* 📚 **Report Card Average**

  * Include your average report card score in the calculation

* 🌐 **Bilingual Interface**

  * English
  * Indonesian

* 🌓 **Dark & Light Themes**

  * Switch between dark and light mode

* 📱 **Responsive Design**

  * Works across desktop, tablet, and mobile screens

* 🔒 **Privacy-Friendly**

  * No account required
  * No sign-in required
  * Calculations are performed in the browser

* 🚫 **No Ads**

  * No advertisements or unnecessary distractions

* ⚡ **Fast**

  * Lightweight React + Vite frontend
  * Client-side calculations
  * Deployed on Vercel

## 📊 Calculation

TKScore currently uses the following calculation model:

### TKA Only

```text
Final Score = (TKA × 60%) + (Report Card × 40%)
```

### TKA + TKAD

```text
Final Score = ((TKA + TKAD) × 60%) + (Report Card × 40%)
```

Individual subject scores are averaged to produce the TKA and TKAD scores.

> **Important:** TKAD support is intended for users in the Special Region of Yogyakarta.

## ⚠️ Disclaimer

TKScore provides **estimates only**.

The results generated by this application are not official scores and do not guarantee admission, acceptance, or final enrollment into any school or educational institution.

Always refer to official government and school admission information for actual requirements, scoring rules, and admission decisions.

## 🚀 Getting Started

### Requirements

Make sure you have installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/sanityguy/tkskor.git
cd tkskor
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.

### Production Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
